python scripts/create_lmdb.py \

## 🔍 速度影响因素分析

### 因素1: 每样本文件数
- 多输入: 17个文件/样本 → **17次PNG解码**
- 单输入: 2个文件/样本 → **2次PNG解码**
- **预期**: 单输入快8-9倍 ⚡⚡⚡

### 因素2: 总样本数
- 多输入: 11,098个样本
- 单输入: 166,470个样本（15倍）
- **影响**: 单输入需要处理更多次

### 因素3: 磁盘配置
- 多输入: F盘→F盘（同盘，可能有磁头竞争）
- 单输入: D盘→E盘（跨盘，读写并行）
- **预期**: 跨盘可能快20-30%

### 因素4: 数据量
- 多输入: 每样本~35MB（17个图像）
- 单输入: 每样本~4MB（2个图像）
- **影响**: 单输入序列化更快

## 📈 速度预测

**多输入LMDB**:
- 样本数: 11,098
