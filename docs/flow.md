## 1. 如何绘制一幅清晰的框架图

要绘制一幅清晰、详尽的整体框架图，建议遵循以下步骤：

1.  **确定核心组件和流程**:
    *   **输入和输出**: 明确模型的起点（例如：原始RGB图像）和终点（例如：增强后的RGB图像）。
    *   **主要模块**: 识别出网络中的关键构建块，如SFE、编码器、解码器、主干网络、各个分支等。
    *   **数据流**: 跟踪数据在模块之间的传递路径，包括主路径和跳跃连接（skip connections）。
    *   **关键操作**: 标注出重要操作，如特征融合（concatenation）、投影（projection）、上采样/下采样等。

2.  **选择合适的工具**:
    *   对于在Markdown中展示，**Mermaid** 是一个绝佳的选择。它允许你用文本描述图表，然后自动渲染成图像。这使得图表的修改和版本控制变得非常方便。
    *   其他工具如 `draw.io` (现在是 `diagrams.net`) 或 `Microsoft PowerPoint/Visio` 也很好，但它们生成的通常是静态图片，不易于在代码仓库中管理。

3.  **设计图表布局**:
    *   **方向**: 决定图表的主要流向，通常是从上到下（`graph TD`）或从左到右（`graph LR`）。对于多阶段的网络，从上到下通常更清晰。
    *   **分组**: 使用子图 (`subgraph`) 将相关的模块组织在一起，例如将整个深度估计阶段或图像增强阶段圈起来，使结构一目了然。
    *   **形状**: 为不同类型的组件选择不同的形状（`[]`代表模块, `{}`代表关键操作, `(())`代表数据/产物），以增强可读性。
    *   **标签**: 给每个模块和连接线清晰地命名。在线上标注传递的数据是什么（例如 `skip_feats`, `depth_pred`）。

4.  **逐步实现图表 (以Mermaid为例)**:
    *   **定义节点**: 为每个组件创建一个节点。例如 `A[原始RGB]`。
    *   **连接节点**: 使用 `-->` 来表示数据流。例如 `A --> B[SFE]`。
    *   **添加标签**: 在连接线上添加文本。例如 `A -->|"RGB图像"| B`。
    *   **使用子图**: `subgraph "阶段一：深度估计" ... end`。

## 框架图超详细绘制说明 (V3 - 基于真实代码实现)

以下是基于实际代码实现的详细框架图绘制指南。所有参数、通道数、模块结构都来自真实的代码分析。

### 核心架构概述
TRINUE模型是一个**两阶段级联结构**：
1. **第一阶段：深度估计** - 使用轻量级U-Net从RGB图像预测深度信息
2. **第二阶段：图像增强** - 融合RGB和深度特征，通过Restormer主干进行去模糊和颜色校正

---

### **第一阶段：深度估计 (Depth Estimation Stage)**

#### 1. **起点: 原始RGB输入**
- **组件**: 绘制输入节点，标记为"原始RGB输入"
- **数据规格**: 三通道彩色图像
- **张量维度**: `[B, 3, H, W]`

#### 2. **浅层特征提取器 (SFE - Shallow Feature Extractor)**
- **组件**: 从输入连接到"SFE"模块
- **内部结构**: 
  ```
  Conv2d(3→48, 3x3, padding=1) → GroupNorm(1) → GELU
  Conv2d(48→48, 3x3, padding=1) → GroupNorm(1) → GELU
  ```
- **功能**: 提取低级纹理和色彩特征，不改变空间分辨率
- **输出**: "浅层RGB特征"
- **张量维度**: `[B, 48, H, W]`
- **关键连接**: **此输出被复用** - 一路送往深度估计分支，另一路通过长跳跃连接送往第二阶段

#### 3. **RGB编码器 (RawEncoder - Pass 1)**
- **组件**: 从SFE连接到"RGB编码器"模块组
- **内部结构** (4个层级):
  - **Level 0**: 输入`[B, 48, H, W]` → ConvBlock(stride=1) + RestormerBlock → 输出`[B, 48, H, W]`
  - **Level 1**: ConvBlock(stride=2) + RestormerBlock → 输出`[B, 96, H/2, W/2]`
  - **Level 2**: ConvBlock(stride=2) + RestormerBlock → 输出`[B, 192, H/4, W/4]`
  - **Level 3**: ConvBlock(stride=2) + RestormerBlock → 输出`[B, 384, H/8, W/8]`
- **跳跃连接**: 每级输出都被保存为`skip_feats`，包含4个不同尺度的特征图
- **RestormerBlock结构**: MDTA(多头深度卷积转置注意力) + GDFN(门控深度前馈网络)

#### 4. **主干瓶颈 (Backbone Bottleneck)**
- **组件**: Level 3输出连接到"主干瓶颈"
- **内部结构**: 若干个RestormerBlock的串联
- **张量维度**: `[B, 384, H/8, W/8]`降

#### 5. **深度解码器 (DepthDecoder)**
- **组件**: U-Net风格的对称解码器
- **输入**: 
  - 主干瓶颈输出: `[B, 384, H/8, W/8]`
  - RGB跳跃特征: `skip_feats` (4个尺度)
- **内部结构** (3次上采样):
  - **Level 3→2**: 上采样(PixelShuffle) + 跳跃连接融合 + RestormerBlock → `[B, 192, H/4, W/4]`
  - **Level 2→1**: 上采样 + 跳跃连接融合 + RestormerBlock → `[B, 96, H/2, W/2]`
  - **Level 1→0**: 上采样 + 跳跃连接融合 + RestormerBlock → `[B, 48, H, W]`
- **输出产物**:
  1. **`depth_pred`**: 通过`Conv2d(48→1) + Sigmoid`生成连续深度图 `[B, 1, H, W]`
  2. **`depth_feats`**: 多尺度深度特征列表，包含4个尺度：
     - Level 0: `[B, 48, H, W]` (最浅层)
     - Level 1: `[B, 96, H/2, W/2]`
     - Level 2: `[B, 192, H/4, W/4]`
     - Level 3: `[B, 384, H/8, W/8]` (最深层，来自原始瓶颈)

---

### **第二阶段：图像增强 (Image Enhancement Stage)**

#### 6. **深度特征投影 (Depth Projection)**
- **组件**: `depth_feats`连接到"深度投影层组"
- **内部结构**: 4个并行的1×1卷积层
  - Level 0: `Conv2d(48→48, 1x1)`
  - Level 1: `Conv2d(96→96, 1x1)`
  - Level 2: `Conv2d(192→192, 1x1)`
  - Level 3: `Conv2d(384→384, 1x1)`
- **功能**: 调整深度特征通道数以匹配RGB编码器特征

#### 7. **特征融合 (Feature Fusion)**
- **组件**: 绘制融合操作节点
- **输入**: 
  - 投影后的深度特征 (4个尺度)
  - SFE的浅层RGB特征 `[B, 48, H, W]`
- **操作**: 在每个对应尺度上进行通道拼接(Concatenate)
- **输出**: "RGB-D联合特征"

#### 8. **第二次编码 (RawEncoder - Pass 2)**
- **组件**: 与第一次编码器结构相同，但处理融合特征
- **特殊功能**: **双向交叉注意力机制**
  - **Depth→RGB注意力**: `CrossAttention`模块，8个头
  - **RGB→Depth注意力**: `CrossAttention`模块，8个头
  - **可学习门控**: 每层都有`γ_d2r`和`γ_r2d`参数控制注意力强度
- **输出**: `student_feats` (4个尺度的增强特征)

#### 9. **Restormer主干 (Joint Bottleneck)**
- **组件**: `student_feats`的最深层连接到"Restormer主干"
- **内部结构**: N个RestormerBlock的顺序堆叠
- **RestormerBlock详细结构**:
  ```
  LayerNorm2d → MDTA(多头深度卷积转置注意力) → 残差连接
  LayerNorm2d → GDFN(门控深度前馈网络) → 残差连接
  ```
- **MDTA**: 使用深度卷积进行空间上下文建模的高效自注意力
- **GDFN**: 门控机制 + 深度可分离卷积的前馈网络
- **输出**: 增强的瓶颈特征 `[B, 384, H/8, W/8]`

#### 10. **物理参数预测头 (Physics Parameter Head)**
- **组件**: 从Restormer主干输出分支出一个"物理参数预测"模块
- **内部结构**:
  ```
  AdaptiveAvgPool2d(1) → Linear(384→128) → ReLU
  Linear(128→4) → 输出[β_c, B_c, blur_scale, 保留参数]
  ```
- **功能**: 预测物理模型参数，用于后续的物理调制

#### 11. **并行解码分支 (MultiTaskDecoder)**
- **组件**: Restormer主干输出送入两个并行分支
- **共同结构**: 每个分支都是3级上采样解码器

##### 11.1 **去模糊分支 (Deblur Branch)**
- **内部结构** (每级):
  ```
  PixelShuffle上采样 → 跳跃连接融合 → RestormerBlock → PSFPML物理调制
  ```
- **PSFPML**: 点扩散函数物理调制层，使用预测的`blur_scale`参数
- **输出**: 去模糊残差 `res_d` `[B, 3, H, W]`

##### 11.2 **颜色分支 (Color Branch)**
- **内部结构** (每级):
  ```
  PixelShuffle上采样 → 跳跃连接融合 → DACBlock → BeerLambertPML物理调制
  ```
- **DACBlock**: 空洞深度可分离卷积 + 通道注意力块
- **BeerLambertPML**: Beer-Lambert定律物理调制层，使用预测的`β_c, B_c`参数
- **输出**: 颜色校正残差 `res_c` `[B, 3, H, W]`

#### 12. **最终重建 (MultiTaskHead)**
- **组件**: 最终的重建模块
- **输入**: 
  - 原始图像 `raw` `[B, 3, H, W]`
  - 去模糊残差 `res_d` `[B, 3, H, W]`
  - 颜色残差 `res_c` `[B, 3, H, W]`
  - 解码器特征 `feat` `[B, 48, H, W]`
- **操作**: 
  1. **图像重建**: `enhanced = tanh(raw + res_d + res_c)`
  2. **深度预测**: `depth_pred = Sigmoid(Conv(feat))` (辅助任务)
- **输出**: 
  - 增强RGB图像 `[B, 3, H, W]`
  - 预测深度图 `[B, 1, H, W]`

## 并行分支超详细结构解析

### **MultiTaskDecoder总体架构**

MultiTaskDecoder是TRINUE模型的核心解码器，负责将Restormer主干的输出特征解码为两种不同的残差：去模糊残差和颜色校正残差。

#### **输入参数**:
- **fused_feat**: `[B, 384, H/8, W/8]` Restormer主干输出的瓶颈特征
- **skip_feats**: 来自第二次编码器的跳跃连接特征列表
  - Level 0: `[B, 48, H, W]`
  - Level 1: `[B, 96, H/2, W/2]`  
  - Level 2: `[B, 192, H/4, W/4]`
- **depth_feats**: 深度特征列表（当前版本中深度融合已禁用）
- **raw**: `[B, 3, H, W]` 原始输入图像
- **物理参数**: `beta_c`, `B_c`, `blur_scale` (来自PhysicsParamHead)

---

### **去模糊分支 (Deblur Branch) 详细解析**

#### **设计理念**
去模糊分支专门处理水下图像的模糊问题，通过PSF(点扩散函数)物理调制层来模拟和逆转水下环境造成的模糊效应。

#### **逐级处理流程**

##### **Level 0 (最深层 → 次深层): H/8×W/8 → H/4×W/4**

**1. PixelShuffle上采样流程**:
```
瓶颈特征 [B, 384, H/8, W/8]
    ↓
1×1卷积扩张通道 (384 → 768通道)
    ↓  
PixelShuffle重排像素 (2倍上采样)
    ↓
输出特征 [B, 192, H/4, W/4]
```

**2. 跳跃连接处理流程**:
```
编码器Level 2跳跃特征 [B, 192, H/4, W/4]
    ↓
双线性插值上采样至目标尺寸
    ↓
1×1卷积投影至基础通道数 (192 → 48通道)
    ↓
投影后跳跃特征 [B, 48, H/4, W/4]
```

**3. 特征融合流程**:
```
上采样特征 [B, 192, H/4, W/4]  +  投影跳跃特征 [B, 48, H/4, W/4]
    ↓
通道拼接操作
    ↓
融合特征 [B, 240, H/4, W/4]
    ↓
1×1卷积降维 (240 → 192通道)
    ↓
输出融合特征 [B, 192, H/4, W/4]
```

**4. PSF物理调制层处理流程**:
```
预测深度图 [B, 1, H, W]
    ↓
计算深度最值 → 深度归一化 → 范围映射至[0,1]
    ↓
上采样深度至当前特征尺寸 [B, 1, H/4, W/4]
    ↓
深度相关模糊强度计算: sigma = blur_scale × 归一化深度
    ↓
1×1卷积特征变换 (1 → 32 → 192通道)
    ↓
加性调制: 融合特征 + 调制增量
    ↓
物理调制后特征 [B, 192, H/4, W/4]
```

**5. RestormerBlock特征精炼流程**:
```
物理调制后特征
    ↓
LayerNorm2d归一化
    ↓
MDTA多头深度卷积转置注意力
    ↓
残差连接
    ↓
LayerNorm2d归一化
    ↓
GDFN门控深度前馈网络
    ↓
残差连接
    ↓
精炼特征输出 [B, 192, H/4, W/4]
```

##### **Level 1: H/4×W/4 → H/2×W/2**

**处理流程** (重复Level 0模式，通道数递减):
```
输入特征 [B, 192, H/4, W/4]
    ↓
上采样 (192 → 96通道, 2倍分辨率)
    ↓
累积跳跃连接 (使用skip_feats[0] + skip_feats[1])
    ↓
特征融合 (96 + 48 + 48 = 192通道)
    ↓
降维投影 (192 → 96通道)
    ↓
PSF物理调制 (深度上采样至H/2×W/2)
    ↓
RestormerBlock精炼
    ↓
输出特征 [B, 96, H/2, W/2]
```

##### **Level 2: H/2×W/2 → H×W**

**最终上采样流程**:
```
输入特征 [B, 96, H/2, W/2]
    ↓
上采样 (96 → 48通道, 2倍分辨率)
    ↓
累积跳跃连接 (使用所有3个跳跃特征)
    ↓
特征融合 (48 + 48×3 = 192通道)
    ↓
降维投影 (192 → 48通道)
    ↓
PSF物理调制 (深度上采样至H×W)
    ↓
RestormerBlock精炼
    ↓
输出特征 [B, 48, H, W]
```

**最终重建流程**:
```
最终特征 [B, 48, H, W]
    ↓
3×3卷积重建头
    ↓
去模糊残差 [B, 3, H, W]
```

---

### **颜色分支 (Color Branch) 详细解析**

#### **设计理念**
颜色分支专门处理水下图像的颜色失真问题，通过Beer-Lambert定律物理调制层来模拟和校正水下光传播造成的颜色衰减。

#### **逐级处理流程**

##### **Level 0: H/8×W/8 → H/4×W/4**

**1-3. 上采样、跳跃连接、融合** (与去模糊分支相同):
```
瓶颈特征上采样 → 跳跃连接投影 → 特征拼接融合
输出融合特征 [B, 192, H/4, W/4]
```

**4. Beer-Lambert物理调制层处理流程**:
```
预测深度图 [B, 1, H, W] + 原始图像 [B, 3, H, W]
    ↓
上采样至当前特征尺寸 [B, 1, H/4, W/4] + [B, 3, H/4, W/4]
    ↓
深度扩展为3通道 [B, 3, H/4, W/4]
    ↓
Beer-Lambert物理量计算:
    透射率: t = exp(-beta_c × 深度)
    后向散射: b = 1 - t  
    归一化图像: I_tilde = 2 × 原始图像 - 1
    ↓
物理特征拼接 [t, b, I_tilde] → [B, 9, H/4, W/4]
    ↓
调制参数预测:
    ReLU激活 (9 → 64通道)
    线性变换 (64 → 384通道)
    参数分离 → gamma, delta (各192通道)
    ↓
仿射变换调制: gamma × 融合特征 + delta
    ↓
物理调制后特征 [B, 192, H/4, W/4]
```

**5. DACBlock处理流程**:
```
物理调制后特征
    ↓
并行路径处理:
    路径1: 深度可分离卷积 (3×3, padding=1)
    路径2: 空洞深度可分离卷积 (3×3, padding=2, dilation=2)
    ↓
特征融合: 路径1 + 路径2
    ↓
通道注意力机制:
    全局平均池化 → 1×1卷积 → Sigmoid激活
    ↓
注意力加权: 融合特征 × 注意力权重
    ↓
输出特征 [B, 192, H/4, W/4]
```

##### **Level 1 & Level 2**
**处理流程** (重复Level 0模式，通道数递减):
```
Level 1: 192 → 96通道, H/4×W/4 → H/2×W/2
Level 2: 96 → 48通道, H/2×W/2 → H×W
每级都重复: 上采样 → 累积跳跃连接 → Beer-Lambert调制 → DACBlock处理
```

**最终重建流程**:
```
最终特征 [B, 48, H, W]
    ↓
3×3卷积重建头
    ↓
颜色校正残差 [B, 3, H, W]
```

### **关键技术特点**

#### **1. 累积跳跃连接 (Dense Skip Connections)**
```
连接模式:
Level 0: 使用 skip_feats[0] (1个跳跃特征)
Level 1: 使用 skip_feats[0] + skip_feats[1] (2个跳跃特征)
Level 2: 使用 skip_feats[0] + skip_feats[1] + skip_feats[2] (3个跳跃特征)

设计优势: 每级获得更丰富的多尺度信息，增强特征表达能力
```

#### **2. 物理感知调制**
```
去模糊分支: PSF物理调制层
    深度相关模糊建模 → 点扩散函数仿真 → 模糊逆转

颜色分支: Beer-Lambert物理调制层  
    水下光传播建模 → 颜色衰减补偿 → 色彩还原
```

#### **3. 通道数变化规律**
```
分支通道演进:
去模糊分支: 384 → 192 → 96 → 48 → 3 (逐级减半)
颜色分支:   384 → 192 → 96 → 48 → 3 (逐级减半)
跳跃特征:   192, 96, 48 → 统一投影为48 (标准化通道)
```

#### **4. 特征融合策略**
```
融合通道数计算规律:
Level 0: 输出通道192 + 1×48基础通道 = 240 → 投影为192
Level 1: 输出通道96 + 2×48基础通道 = 192 → 投影为96  
Level 2: 输出通道48 + 3×48基础通道 = 192 → 投影为48

设计理念: 随着层级加深，融合更多历史信息
```

#### **5. 物理参数控制**
```
消光系数 beta_c [B, 3, 1, 1]: 控制RGB三通道的光衰减强度
背景光 B_c [B, 3, 1, 1]: 补偿水体背景光的颜色偏移
模糊尺度 blur_scale [B, 1, 1, 1]: 调节深度相关的模糊程度

参数范围: beta_c, blur_scale ≥ 0 (softplus), B_c ∈ [0,1] (sigmoid)
```

### **整体设计优势**

这种精心设计的并行分支架构具有以下优势：

1. **任务专业化**: 两个分支分别专注于去模糊和颜色校正，避免任务间的相互干扰
2. **物理约束**: 基于水下成像物理模型的调制层，提供强先验知识指导
3. **多尺度融合**: 累积跳跃连接保证了丰富的多尺度特征传递
4. **自适应调制**: 物理参数由网络自动预测，实现自适应的图像修复
5. **高效重建**: 残差学习方式减少了网络学习负担，提高收敛速度

能够有效地分别处理水下图像的模糊和颜色失真问题，实现高质量的图像复原。

### **关键连接关系说明**

1. **跳跃连接传递**: 每个Level都会接收来自第二次编码器对应层的特征，并且随着层级增加，累积使用越来越多的跳跃特征。

2. **物理参数共享**: PhysicsParamHead预测的物理参数在两个分支中都被使用，但调制方式不同。

3. **并行处理**: 两个分支完全并行处理，互不干扰，最后通过残差融合方式合并结果。

4. **多尺度信息流**: 从最深层(H/8×W/8)逐步上采样到原始分辨率(H×W)，每级都融合相应的跳跃特征。

5. **物理感知调制**: 每级都应用物理调制，深度信息会被上采样到对应分辨率参与调制过程。
